# 💖 Sponsorship & Sustainable Development

MeshCards is built as an open platform to help students worldwide. To cover API costs and infrastructure, we offer a specialized **Sponsor Experience**.

## 🎁 Sponsor Benefits

Becoming a sponsor $(\$5+/month)$ unlocks premium features and higher utility:

- **Enhanced Daily Quota**: 5 decks per day using system keys (vs 2 for free users).
- **Rare Model Access**: Direct access to high-reasoning models like **Llama 3.3 70B** and **Qwen 2.5 72B** without needing your own API key.
- **Priority Support**: Direct line of communication for feature requests and bug fixes.
- **Sponsor Badge**: A verified aesthetic badge in the Configuration panel celebrating your support.

## 🌈 The Premium UI Experience

When a user is verified as a sponsor, the interface reflects their status:
1. **Verified Badge**: A gradient-styled "Verified Sponsor" indicator with micro-animations.
2. **Unlocked Models**: Premium models in the dropdown appear as "Unlocked" or "Unlimited Access".
3. **No Hard Blocks**: Sponsors are discouraged from being hard-blocked by quotas; messaging focus on "Thank you" rather than "Limits".

## 🚀 How to Support

1. **Visit**: [Buy Me a Coffee](https://buymeacoffee.com/htclodkzgo)
2. **Email Sync**: Ensure your BMC email matches your MeshCards login (Supabase).
3. **Activation**: Verification usually completes within 24 hours via automated check against the Supabase `sponsors` database.

## 🤝 Project Philosophy

- **Transparency**: We clearly communicate model costs and API limits.
- **Community-Driven**: Sponsors can request new models (e.g., Claude 3.5 Sonnet) via the feedback system.
- **Sustainable**: Every ☕ contributed goes directly toward Novita/Google API credits to keep the service running.
